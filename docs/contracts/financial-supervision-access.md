# Financial supervision access

Effective 2026-10-19, this policy supersedes earlier permissions granting ADMIN financial writes in the FASE 16 authorization matrix and FASE 20 savings contract.

- ADMIN may read savings accounts, balances, passbooks, transactions, and settlements across all classes and academic years.
- ADMIN may not create savings accounts, deposit, withdraw, edit or cancel transactions, settle accounts, or reopen settlements.
- WALI_KELAS retains account creation and financial operations within assigned class/year scope.
- SISWA retains read access only to their own account.
- No current role may reopen settlements. The former ADMIN-only reopening permission is withdrawn; a replacement approval workflow is not defined.
- Admin navigation uses “Pengawasan Tabungan” and hides the transaction entry menu. Account creation controls are restricted to WALI_KELAS. Service authorization is authoritative even for direct calls.

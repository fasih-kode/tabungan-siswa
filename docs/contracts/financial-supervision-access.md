# Financial supervision access

Effective 2026-10-20, this policy supersedes earlier permissions granting ADMIN financial writes in the FASE 16 authorization matrix and FASE 20 savings contract. The FASE 23 reopen approval workflow below is a narrow exception for controlled correction of a closed year.

- ADMIN may read savings accounts, balances, passbooks, transactions, and settlements across all classes and academic years.
- ADMIN may not create savings accounts, deposit, withdraw, edit or cancel transactions, settle accounts, execute reopening, or perform financial corrections. ADMIN may approve or reject a Wali Kelas reopen request with a recorded reason; the requester cannot approve their own request.
- WALI_KELAS retains account creation and financial operations within assigned class/year scope.
- SISWA retains read access only to their own account.
- Only the historically responsible WALI_KELAS may request and execute a reopen after a distinct ADMIN approval. This permission is limited to the approved account and year, and is unavailable once a successor academic year exists.
- Admin navigation uses “Pengawasan Tabungan” and hides the transaction entry menu. Account creation controls are restricted to WALI_KELAS. Service authorization is authoritative even for direct calls.
